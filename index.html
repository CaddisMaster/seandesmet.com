Material List Import Tool

private

Turns a builder's takeoff — an Excel material list for a house — into a CSV the point-of-sale system can import. It matches free-text descriptions to item numbers, a person reviews every line, and a catalog learns from each confirmation so the same line never needs matching twice.

  1. upload
  2. parse
  3. match
  4. review
  5. csv

every confirmation teaches the catalog

first run · empty catalog

A 144-line house to import-ready CSV in 9 minutes, on 2 model calls, for 16¢ — with 99% of the AI's proposals accepted unchanged.

features

  • .xlsx, .xls and .csv upload
  • AI parsing; repeat layouts need no call
  • Catalog match first, AI only for the rest
  • Confidence-scored proposals
  • A person reviews every line
  • Reports: time saved, match rate, AI cost

engineering

  • Tests never call the real API (enforced)
  • Protected main, required CI checks
  • Non-root Docker image
  • Forward-only migrations
  • CSRF, rate limiting, CSV-injection guard
